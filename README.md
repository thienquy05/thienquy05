## About

I'm a Computer Science student who spends most of his week doing actual security operations, not just reading about them.

As a **Tier 2 IT System Administrator at the University of Toledo**, I manage **1,000+ Windows and macOS endpoints** through Active Directory and Microsoft Intune. In one recent four-month stretch I responded to **15+ security incidents**, including remediating unpatched Windows 10 machines with open vulnerabilities and isolating malware-infected devices from the network.

The rest of my time goes into building things that break, then figuring out why. Most of what's pinned below started as a question I couldn't answer without writing code.

- Enforcing device compliance and triaging security alerts across a live enterprise fleet
- Building detection tooling, mostly in Python
- Studying for **CompTIA A+**, working through TryHackMe and HackTheBox
- Graduating **December 2027**
